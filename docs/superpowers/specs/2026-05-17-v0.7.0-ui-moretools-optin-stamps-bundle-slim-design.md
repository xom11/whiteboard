# v0.7.0 — UI cleanup + opt-in stamps + bundle slim

**Status**: approved (design only — implementation plan separate)
**Date**: 2026-05-17
**Target version**: `@xom11/whiteboard` 0.6.5 → 0.7.0 (breaking)
**Downstream**: HocTotBachKhoa (chỉ consumer hiện tại, dùng Next.js)

## Mục tiêu

1. Dọn UI: gom toàn bộ stamp buttons vào popover "More tools" của Excalidraw (bỏ inline desktop).
2. Sửa icon stamp 3D (hexagon → cube isometric).
3. Cho consumer tắt feature chưa production-ready dễ dàng: 3D + graph2d chuyển sang opt-in.
4. Audit + slim bundle, structure, deps, test setup.

## Non-goals

- Không viết PR ngược lên Excalidraw upstream.
- Không tách `MiniBoard.tsx` (1308 dòng) — risk regression cao, để bản sau.
- Không đổi test runner (jest → vitest).
- Không đụng tới persistence layer hay scene sync logic.

## 1. UI — gom stamps vào More tools dropdown

### Hiện trạng

`src/stamps/shared/ToolbarInjector.tsx` (438 dòng) có 2 nhánh inject:

- **Desktop** (`!isMobile`): inject `<button class="ToolIcon Shape">` inline vào `.App-toolbar .Stack_horizontal`, trước nút `.App-toolbar__extra-tools-dropdown`.
- **Mobile** (`.excalidraw.excalidraw--mobile` có class): inject `.dropdown-menu-item` vào `.dropdown-menu--mobile .dropdown-menu-container` khi popover mở.

Detect mobile bằng `MutationObserver` trên class của `.excalidraw` root.

### Thiết kế mới

- **Bỏ nhánh inline desktop hoàn toàn**.
- **Một nhánh inject duy nhất**: tìm `.dropdown-menu-container` bên trong `.App-toolbar__extra-tools-dropdown` (selector này cover cả desktop popover lẫn mobile popover do Excalidraw render cùng component cho cả 2 mode).
- `MutationObserver` quan sát `.excalidraw` root để detect khi popover mount/unmount.
- Khi mount: insert wrapper `#stamp-menu-portal-wrapper` ở đầu `dropdown-menu-container`, render `<StampMenuItem>` cho từng stamp qua `createPortal`.
- Khi popover unmount (user click ra ngoài hoặc bấm stamp), wrapper auto-remove cùng popover (DOM gốc của Excalidraw dispose).
- Sau khi click 1 stamp menu item, gọi `closeMobileMenu()` (đổi tên thành `closeMoreToolsPopover()`) để collapse popover cho cả 2 mode.

### File ảnh hưởng

- `src/stamps/shared/ToolbarInjector.tsx`: rewrite, giảm ~120 dòng (chỉ giữ menu-mount logic + `StampMenuItem`). Xóa `StampToolButton`, `isMobile` state, 2 useEffect tách biệt.
- `src/stamps/shared/__tests__/ToolbarInjector.test.tsx`: cập nhật test (mock popover container, assert stamps render bên trong).

### Tradeoff đã chấp nhận

- User mất 1 click so với inline desktop. Đổi lại: main toolbar Excalidraw sạch + consistent với mobile + dễ scale khi thêm stamp mới.

```ts
export const DEFAULT_STAMPS = Object.freeze([
  geometryStamp, latexStamp, geometry3dStamp, graph2dStamp,
]);
```

Consumer muốn tắt 3D phải biết import cả `geometryStamp` + `latexStamp` rồi pass `stamps={[geometryStamp, latexStamp]}`.

### Thiết kế mới

```ts
// registry.ts
export const STABLE_STAMPS = Object.freeze([geometryStamp, latexStamp] as const);
export const EXPERIMENTAL_STAMPS = Object.freeze([geometry3dStamp, graph2dStamp] as const);
export const ALL_STAMPS = Object.freeze([...STABLE_STAMPS, ...EXPERIMENTAL_STAMPS]);
```

```ts
export interface StampType {
```

### File ảnh hưởng

- `src/stamps/graph-2d/index.tsx`: set `experimental: true`.
- `src/stamps/index.ts`: re-export `STABLE_STAMPS`, `EXPERIMENTAL_STAMPS`, `ALL_STAMPS`.
- `src/index.ts`: idem.
- `README.md`: cập nhật migration guide.
- `CHANGELOG.md` (tạo mới nếu chưa có): document breaking change.

## 4. Architecture audit + cải thiện

### A. Lazy-load stamp Host

**Hiện trạng**: `geometryStamp.Host = GeometryStampHost` ref trực tiếp tới component → bundle vào main entry. JSXGraph (~470KB src) + KaTeX (~280KB src) load ngay khi consumer mount `<Whiteboard />`.

**Mới**: mỗi stamp expose `Host` qua `React.lazy`:

```ts
// src/stamps/geometry-2d/index.tsx
const GeometryStampHost = lazy(() =>
  import('./host').then(m => ({ default: m.GeometryStampHost }))
);

export const geometryStamp: StampType = {
  // ...
  Host: GeometryStampHost, // vẫn cùng type, internal là lazy
};
```

Tách `geometry-2d/index.tsx` thành:
- `geometry-2d/index.tsx`: chỉ giữ stamp metadata (icon, kind, matchesCustomData, lazy Host).
- `geometry-2d/host.tsx`: code Host (forwardRef, editor wiring).

`Whiteboard.tsx` wrap `<HostComponent />` trong `<Suspense fallback={null}>`.

### B. Drop `next/dynamic` → `React.lazy`

**Hiện trạng** (`src/Whiteboard.tsx` line 27–37):
```ts
import dynamic from 'next/dynamic';
const Excalidraw = dynamic(
  async () => (await import('./ExcalidrawWithMenus')).ExcalidrawWithMenus,
  { ssr: false, loading: () => <div>...</div> },
);
```

**Mới**:
```ts
import { lazy, Suspense } from 'react';
const Excalidraw = lazy(() =>
  import('./ExcalidrawWithMenus').then(m => ({ default: m.ExcalidrawWithMenus }))
);
// Whiteboard component chỉ render <Excalidraw> trên client (đã có 'use client' banner)
// SSR-safe vì cả file 'use client' → Next.js render trên client.
```

Wrap `<Excalidraw>` trong `<Suspense fallback={<LoadingPlaceholder />}>`.

Update `package.json`:
```json
"peerDependencies": {
  "react": ">=18.0.0",
  "react-dom": ">=18.0.0"
}
```
(Drop `next`.)

### C. Subpath exports

`package.json` thêm:

```json
  "./geometry-3d": { ... },
```

`tsup.config.ts` thêm entries:

Consumer chỉ trả tiền bundle stamp mà họ thực sự import. Kết hợp với (A), bundle initial của HocTotBachKhoa drop xuống ~80KB.

### D. Extract hooks ra khỏi `Whiteboard.tsx`

`Whiteboard.tsx` hiện 531 dòng. Tách 3 concerns ra:

| Hook | Concern | File mới | Dòng ước tính |
|------|---------|----------|--------------|
| `useStampDoubleClick` | Detect double-click image element → openStamp | `src/stamps/shared/useStampDoubleClick.ts` | ~40 |
| `useStampShortcutBlocker` | Khi panel mở, block phím Excalidraw tool shortcuts | `src/stamps/shared/useStampShortcutBlocker.ts` | ~50 |
| `useStampClickOutside` | Click ra ngoài → tryInsert + closeStamp | `src/stamps/shared/useStampClickOutside.ts` | ~30 |

`Whiteboard.tsx` sau khi extract: ~350 dòng, dễ đọc hơn.

### Bundle estimate

| Asset | Trước (v0.6.5) | Sau (v0.7.0) |
|-------|----------------|--------------|
| Main entry (`dist/index.mjs`) | 299 KB | ~80 KB |
| `dist/geometry-2d.mjs` (lazy) | (bundled) | ~110 KB |
| `dist/geometry-3d.mjs` (lazy) | (bundled) | ~140 KB |
| `dist/latex.mjs` (lazy) | (bundled) | ~80 KB |
| `dist/graph-2d.mjs` (lazy) | (bundled) | ~90 KB |
| First-load cost cho consumer chỉ dùng default | 299 KB | ~80 KB + lazy khi user mở editor |

→ Initial bundle giảm ~73%.
