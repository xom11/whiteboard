# Undo/Redo cho Geometry 2D + 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thêm cặp nút Undo/Redo đối xứng cho editor hình học 2D và 3D, kèm phím tắt Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y, hiện cả trong panel desktop, drawer mobile và header bar mobile.

**Architecture:**
- 2D: tận dụng `creationLogRef` đã có; bổ sung `redoStackRef`; refactor đoạn re-create object từ `SerializedElement` thành function dùng chung cho cả initial-load và redo.
- 3D: thêm history layer vào `Scene3D` dạng snapshot toàn state; built-in mutations tự `capture()` trước khi mutate; drag flow snapshot-at-drag-start + `pushUndoCheckpoint` ở drag-end; host subscribe `onHistoryChange` để cập nhật UI.

**Tech Stack:** TypeScript strict, React 18 hooks, JSXGraph 1.x, Jest 29 + jsdom + ts-jest, Tailwind v4.

**Spec reference:** `docs/superpowers/specs/2026-05-17-undo-redo-2d-3d-design.md`

```ts
      // Tái dựng 1 object từ entry log đã serialize. Dùng chung cho cả
      // initial-state replay và redo. Trả về true nếu tạo thành công, false nếu
      // entry không tái dựng được (vd: valueLabel mất target).
      const recreateFromLogEntry = (el: SerializedElement): boolean => {
        const idMap = objMapRef.current;
        const resolved = el.args.map(a => (typeof a === 'string' && idMap.has(a)) ? idMap.get(a) : a);
        try {
          if (el.type === 'valueLabel') {
            const target = resolved[0];
            if (!target) return false;
            const txt = createValueLabelFor(target);
            if (!txt) return false;
            idMap.set(el.id, txt);
            valueLabelsRef.current.set(target, txt);
            return true;
          }
          const themedAttrs = resolveAttrColors({ ...el.attrs }, paletteFor(isDarkRef.current));
          const obj = board.create(el.type, resolved, themedAttrs);
          idMap.set(el.id, obj);
          return true;
        } catch (err) {
          console.warn('Recreate failed for', el.type, err);
          return false;
        }
      };
```

    const b = boardRef.current;
    if (!b) return;
    while (creationLogRef.current.length > 0) {
      const last = creationLogRef.current.pop();
      if (!last) break;
      const obj = objMapRef.current.get(last.id);
      objMapRef.current.delete(last.id);
      if (obj) {
        try { b.removeObject(obj); } catch { /* ignore */ }
        clearPending();

        redoStackRef.current.push(last);

        try { b.update(); } catch { /* ignore */ }
        return;

      // Skip stale log entry (object đã biến mất từ trước) — không push vào redoStack

  }, [clearPending]);

  const redoNext = useCallback(() => {
    const b = boardRef.current;
    if (!b) return;
    const entry = redoStackRef.current.pop();
    if (!entry) {
      setHistoryTick((t) => t + 1);
      return;

    const ok = recreateFromLogEntry(entry);
